How to use itUpload a video or image
Set width / FPS / duration (start with 480 px @ 12 fps for mobile-safe sizes)
Add optional text
Generate → download or save to your local library
Search / export / import the library as JSON

Community Gallery that loads from a gallery.json file in the repo (people can contribute via Pull Request)

How community gallery worksCreate a file gallery.json in the same repo (example below).
Contributors export a GIF, then open a PR that adds an entry to gallery.json.
The app loads it automatically from the same origin.
